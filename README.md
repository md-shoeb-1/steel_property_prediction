# Steel Property Prediction Dataset

This repository contains the curated dataset used in the manuscript:

"An Explainable Machine Learning Framework for Interpretable Mechanical Property Prediction in Steels Using Alloy Composition and Heat Treatment."

The dataset includes:
- Steel grades
- Alloy compositions
- Heat-treatment conditions
- Mechanical properties (Su, Sy, BHN, A5)

The data were curated from publicly available sources including the Autodesk Material Library (via Kaggle), MatWeb, and SAE specifications.
